9장. 신경망에서 딥러닝으로

강의 핵심오차 역전파는 개념만 · 기울기 소실 · 활성화 함수 4가지(“시험 나올 수 있으니까”) · 고급 경사하강법(“이거는 알아두십시오”) · 렐루 + 아담

오차 역전파: 은닉층의 가중치를 고치는 방법

  • 다층 퍼셉트론으로 XOR은 풀었지만, 가중치·바이어스를 사람이 미리 정해 준 것 → 모델링이라 할 수 없음. 컴퓨터가 데이터로 스스로 가중치를 조정해야 함
  • 문제: 은닉층의 가중치를 업데이트할 방법이 없었음 → 인공지능의 겨울 → 힌튼 교수의 오차 역전파로 해결 → 딥러닝의 시작
  • 순전파 = 입력층 → 출력층으로 순서대로 계산 (폭포가 위에서 아래로) / 역전파 = 출력의 오차를 거꾸로 거슬러 올라가며(연어) 각 층의 가중치를 수정
  • 오차 역전파 = 출력에서 구한 오차를 입력층 쪽으로 보내며 경사하강법으로 가중치를 고치는 방법. 단일 퍼셉트론은 경사하강법 한 번이면 되지만, 은닉층이 생기면 두 번(층마다) 경사하강법을 해야 함
  • 과정: ① 가중치 초깃값을 정함 → ② 순전파로 출력값 계산 → ③ 실제값과 비교해 오차 계산 → ④ 오차가 줄도록 출력층 → 은닉층 순으로 가중치 수정(역전파 1, 역전파 2) → 반복
  • 은닉층은 겉으로 드러나지 않아 “정답(실제값)”이 없음 → 출력층의 오차를 이용해 편미분으로 계산 (계산법은 몰라도 됨)
  • 경사하강법(5장 복습) = 임의의 가중치로 오차를 구한 뒤, 기울기의 반대 방향으로 조금씩 이동해 오차가 최소(기울기 0)인 곳을 찾는 방법

강의 2:17“실제로 저희는 계산 방법까지는 몰라도 된다. 오차 역전파의 개념이 뭐던지” · 2:35“개념 정도만 익히고 넘어가는 것을 목적으로 합니다”

기울기 소실 문제

  • 기울기 소실 = 층을 깊게 쌓으면 역전파가 진행될수록 기울기가 점점 0에 가까워져, 출력층에서 시작한 가중치 업데이트가 처음 층까지 전달되지 않는 현상 (사람으로 치면 “치매”)
  • 원인 = 활성화 함수로 쓴 시그모이드. 시그모이드를 미분하면 최댓값이 0.25 → 층을 지날 때마다 25% 이하만 남아 곱할수록 0에 가까워짐 → 풀이 ⑤
  • 은닉층을 두껍게 쌓으면 정확도가 오를 것 같지만, 너무 깊으면 기울기 소실 + 비용 증가 → 적절한 은닉층 개수가 필요 (정수기 필터 100층에서는 물이 안 나옴)

강의 9:11“학습을 더 이상 할 수 없는 기울기 소실 문제 발생해요. 요거는 알아두시면 좋고” · 9:35“시그모이드 함수를 미분하면 최대치는 0.25기 때문에”

활성화 함수 4가지

활성화 함수특징
시그모이드S자, 값 0 ~ 1. 미분 최댓값 0.25 → 기울기 소실의 원인. 지금은 이진 분류의 출력층에 씀
하이퍼볼릭 탄젠트 (tanh)시그모이드를 −1 ~ 1로 넓힌 S자. 그래도 미분값이 1보다 작아 기울기 소실이 남음
렐루 (ReLU)x < 0 → 0, x > 0 → x 그대로. x > 0이면 미분값이 1 → 입력 대비 출력이 보장되어 첫 층까지 전달. 가장 많이 씀
소프트플러스렐루의 0이 되는 부분을 부드럽게 완화한 함수
  • 활성화 함수 4가지 이름과 특징: 시그모이드, 하이퍼볼릭 탄젠트, 렐루, 소프트플러스
  • 렐루가 기울기 소실을 100% 해결한 것은 아니지만, x가 0보다 크면 미분값이 1이라 오차 역전파가 여러 층을 지나도 맨 처음 층까지 갈 수 있음 → 대부분의 딥러닝 은닉층에 렐루를 씀
  • 렐루의 약점: 입력이 0보다 작으면 모두 0으로 리셋 (하지만 그런 경우가 드물어 보편적으로 사용)
  • 학습 = 오차를 최소화하는 가중치를 찾는 과정 → 역전파로 입력층까지 고칠 수 있게 되면서 깊은 층을 쌓을 수 있게 됨

강의 11:12“보편적으로 사용되는 함수는 뭐다? 렐루 함수들. 요거는 네 가지는 알아두시길 바랍니다. 시험 나올 수 있으니까”

고급 경사하강법 (옵티마이저)

  • 일반 경사하강법은 정확하지만 계산량이 매우 많음(전체 데이터를 매번 씀) → 데이터가 많을수록 시간이 오래 걸리고, 최솟값이 아닌 곳에서 멈출 수도 있음 → 고급 경사하강법 등장
방법개요개선
확률적 경사하강법 (SGD)전체가 아니라 랜덤하게 뽑은 일부 데이터로 더 자주 업데이트. 중간 결과가 출렁이지만(불안정) 빠르고 최적 근삿값을 찾음속도
모멘텀경사에 관성(탄력)을 더함. 바로 앞 수정 방향을 참고해 같은 방향으로 일정 비율만 수정 → 지그재그 진동이 줄고 완만하게정확도(방향)
네스테로프 모멘텀모멘텀이 이동할 방향으로 미리 가서 기울기를 계산 → 불필요한 이동 줄임정확도(방향)
아다그라드 (Adagrad)자주 업데이트되는 변수는 학습률을 작게 → 보폭 조절보폭
RMSProp아다그라드의 보폭 민감도를 보완보폭
아담 (Adam)모멘텀 + RMSProp을 합침 → 두 마리 토끼(정확도와 보폭)를 동시에. 가장 많이 씀정확도 + 보폭
  • 고급 경사하강법 표: 방향을 고치는 것 = 모멘텀 계열, 보폭을 고치는 것 = 아다그라드 · RMSProp, 둘 다 = 아담
  • 아담 = 모멘텀 + RMSProp (“제일 중요한”). 아다그라드 · RMSProp은 빅데이터·인공지능 자격증 시험에 자주 나옴
  • 옵티마이저 = 오차를 최소화하는 경사하강법(최적화 방법)을 딥러닝에서 부르는 말 → 코드의 optimizer='adam' / 활성화 함수는 activation='relu'
  • 정리: 활성화 함수 = 렐루, 옵티마이저 = 아담을 가장 많이 씀 (뒤 장 코드에 계속 나옴)

강의 16:49“경사하강법은 다음과 같이 나와야돼. 이거는 알아두십시오” · 17:04“아다그라드, RMSProp 시험에 자주 나오는 거” · 17:20“모멘텀과 RMSProp을 합쳐서 두 마리 토끼를 동시에 잡으려고 한게 아담” · 17:42“활성 함수로는 렐루라는게 많이 쓰이고요. 옵티마이저는 아담이라는게 많이 씁니다”

몰라도 되는 것 오차 역전파 계산법(델타식·편미분 계산, “계산 방법까지는 몰라도 된다”), 모멘텀 등 각 방법의 자세한 설명(“이걸 다 외우실 필요는 없고” → 표의 이름·개선점만), 케라스 옵티마이저 인자값

10장. 딥러닝 모델 설계하기

강의 핵심모델 정의 → 컴파일 → 학습 · 손실 함수(“두 가지 세 가지 정도만 일단 기억”) · 에포크 · 배치 사이즈(하이퍼파라미터)

딥러닝 모델 만드는 순서

  • 모델 정의(구조 설계: 입력 → 은닉 → 출력 층과 노드 수) → 컴파일(손실 함수 · 옵티마이저 · 평가 기준 설정) → 학습(fit)
  • 텐서플로를 더 쉽게 쓰려고 나온 것이 케라스. Sequential로 모델을 만들고 Dense로 층을 쌓음
  • 폐암 수술 환자 데이터: 환자 470명, 속성 16개(0 ~ 15번 열 = X) + 클래스 1개(16번 열 = y, 생존 1 / 사망 0)
  • 구조: 입력 16 → 은닉층 노드 30(렐루) → 출력 1(시그모이드, 생존/사망 둘 중 하나) → 가중치·바이어스 541개 → 풀이 ①
model = Sequential()
model.add(Dense(30, input_dim=16, activation='relu'))   # 입력 16 → 은닉 30
model.add(Dense(1, activation='sigmoid'))                # 출력 1 (이진 분류)
model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])
history = model.fit(X, y, epochs=5, batch_size=16)

손실 함수(오차 함수)

문제출력층 활성화손실 함수(loss)
이항 분류 (둘 중 하나: 생존/사망)시그모이드binary_crossentropy
다항 분류 (셋 이상 중 하나: 붓꽃 품종)소프트맥스categorical_crossentropy
수치 예측 (회귀: 집값)없음(값 그대로)mean_squared_error (평균 제곱 오차)
  • 손실 함수 = 예측과 실제의 차이(오차)를 계산하는 함수. 이항 분류 → 바이너리 크로스 엔트로피, 다항 분류 → 카테고리컬 크로스 엔트로피, 수치 예측 → 평균 제곱 오차(MSE)
  • 옵티마이저는 아담(모멘텀 + RMSProp), 평가 기준은 정확도 metrics=['accuracy']
  • 출력에 나오는 loss = 손실값, accuracy = 정확도, val_로 시작하면 검증셋 기준 (14장)

강의 5:30“이항 분류는 보통 바이너리 크로스 엔트로피, 다항 분류 … 세 가지 이상 분류할 때는 카테고리컬 크로스엔트로피를 보통 로스 함수로 많이 사용한다라는 거 알고 계시면 되고” · 5:55“두 가지 세 가지 정도만 일단 기억을 해 두시면 좋을 것 같아요”

에포크와 배치 사이즈

  • 에포크(epochs) = 전체 데이터를 몇 번 반복해서 학습할지 (책 전체를 몇 번 독파했는지) / 배치 사이즈(batch_size) = 한 번에 몇 개씩 끊어서 학습할지 (하루 공부량)
  • 폐암 예제: 470개 샘플을 16개씩 끊어서, 전체를 5번 반복 → 풀이 ⑥
  • 배치 사이즈가 너무 크면 속도가 느려지고, 너무 작으면 편차가 생겨 결과가 불안정
  • 하이퍼파라미터 = 사용자가 직접 정하는 값. 에포크 · 배치 사이즈 · 은닉층 수 · 노드 수 등

강의 7:08“하루 공부량 배치 사이즈고요. 이 전체를 몇 번 독파했는지 독파의 수가 에포크가 된다” · 7:36“배치 사이즈도 사용자가 다루는 하이퍼 파라미터 중 하나다라고 알아두시면 좋을 것 같아요”

다중 분류와 아이리스 데이터

  • 다중 분류 = 여러 개의 답 중 하나를 고르는 분류 (숫자·글자 맞히기, 품종 맞히기) / 이항 분류 = 둘 중 하나(O/X)를 고르는 분류 → 접근 방식이 다름
  • 아이리스(붓꽃) 데이터: 150개, 속성 4개(꽃받침 길이·너비, 꽃잎 길이·너비) + 클래스 3개 품종(세토사, 버지컬러, 버지니카)
  • sns.pairplot(df, hue='species') = 속성끼리 짝지어 분포를 한눈에 봄. hue = 어떤 카테고리(품종)를 기준으로 색을 나눌지. 대각선 = 해당 속성 하나의 분포
  • species 열은 문자열(object 타입) → 계산하려면 숫자로 바꿔야 함

원-핫 인코딩

  • 원-핫 인코딩 = 여러 개의 값으로 된 문자열을 0과 1로만 이루어진 형태로 바꾸는 것. 클래스 이름마다 열을 만들고, 자기 이름이면 1 나머지는 0
  • 예: A → [1, 0, 0], B → [0, 1, 0], C → [0, 0, 1]. 판다스 pd.get_dummies(y)로 처리
  • 열이 늘어나 데이터가 커 보이지만(속성 4 + 클래스 3 = 7열 × 150행) 학습에는 유리. 실제로 열이 100 ~ 200개씩 늘기도 함
  • 학습에 유리한 순서: 문자 < 숫자, 숫자 중에서도 정수보다 0과 1 사이의 실수가 유리

강의 6:41“문자보다 숫자가 유리하고요. 숫자 중에서도 정수 타입보다는 0과 1 사이의 실수 타입이 조금 더 학습에 유리하다” · 8:51“여러 개의 값으로 된 문자열을 0과 1로만 이루어진 형태로 만들어 주는 과정을 원핫 인코딩이라 하고요”

소프트맥스와 카테고리컬 크로스 엔트로피

  • 소프트맥스 = 다중 분류의 출력층에 쓰는 활성화 함수. 각 클래스일 확률을 내고, 모두 더하면 1 (예: A 0.1, B 0.3, C 0.6 → C일 확률이 가장 높음) → 풀이 ⑦
  • 이항 분류는 출력 1개(시그모이드, 0.5 이상이면 1), 다중 분류는 출력 노드 = 클래스 수(소프트맥스) + 손실 함수 categorical_crossentropy
  • 구조: 입력 4 → 은닉 12 → 은닉 8 → 출력 3(소프트맥스). 에포크 50, 배치 5 → 정확도 약 96%(150개 중 144개) → 풀이 ③
y = pd.get_dummies(y)                                  # 원-핫 인코딩

13장. 모델 성능 검증하기 (초음파 광물)

강의 핵심과적합 · 학습셋과 테스트셋 나누기 · 과적합 그래프(테스트셋 오차가 다시 커짐) · K겹 교차 검증

초음파 광물 데이터와 100% 정확도

  • 1986년 힌튼의 오차 역전파 발표 후, 세즈노프스키 교수가 은닉층 가중치가 실제로 업데이트되는지 확인하려고 광석과 일반 암석에 음파 탐지기를 쏴서 만든 데이터
  • 208개 샘플, 속성 60개 + 클래스 1개(광석 1 / 일반 암석 0) = 61열
  • 구조: 입력 60 → 은닉 24 → 은닉 10 → 출력 1(시그모이드, binary_crossentropy). 에포크 200, 배치 10 → 정확도 100%
  • 학습한 데이터로 그대로 시험을 쳤기 때문 (공부한 문제로 시험 → 성적이 높을 수밖에 없음) → 정말 어떤 광물이든 100% 맞히는 모델일까?

과적합

  • 과적합(오버피팅) = 모델이 학습 데이터셋 안에서는 높은 정확도를 보이지만 새로운 데이터에는 잘 맞지 않는 것. 주어진 샘플에만 너무 최적화된 상태 (하늘은 파랗다고만 배운 사람이 노을을 보고 “하늘이 아니다”라고 함)
  • 언더피팅 = 학습이 부족해 분류를 제대로 못 하는 상태 / 좋은 모델 = 조금 틀려도 유연성이 있는 선 / 과적합 = 학습 데이터는 완벽히 나누지만 일반적이지 않은 선
  • 과적합의 원인: 층이 너무 많거나, 변수가 복잡하거나(노드가 너무 많음), 학습셋과 테스트셋이 중복될 때
  • 98%와 100%는 2% 차이지만, 그 2%에 지금까지 쓴 비용 이상이 들 수 있음

강의 6:10“과적합이라는 것은 모델이 학습 데이터셋 안에서는 일정 수준 이상의 예측과 정확도를 보이지만 새로운 데이터에 적용하면 잘 맞지 않는다” · 8:31“과적합이란 문제에 빠지지 않도록 늘 주의해야 된다”

학습셋과 테스트셋 나누기

  • 과적합을 막는 가장 간단한 방법 = 학습셋(공부용)과 테스트셋(시험용)을 분리. 보통 7 : 3(또는 8 : 2, 85 : 15), 랜덤으로 나눔 → 풀이 ⑧
  • 학습셋 70개로 공부해 모델을 만들고, 나머지 30개로 정확도 확인 (교과서만 보는 게 아니라 기출 문제로 확인) → 가장 나은 모델을 실생활에 적용 = 머신러닝 개발 순서
  • 앞 장 예제(폐암, 피마, 아이리스)는 나누지 않고 전체로 테스트 → 새 데이터에서 성능은 알 수 없음. 머신러닝의 최종 목적 = 새로운 데이터에서 좋은 결과
  • train_test_split(X, y, test_size=0.3, shuffle=True) (사이킷런) = 테스트 30%, 섞어서 나눔 / model.evaluate(X_test, y_test) = loss와 accuracy 두 값을 반환 → 광물 데이터 테스트 정확도 약 84%
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, shuffle=True)
history = model.fit(X_train, y_train, epochs=200, batch_size=10)
score = model.evaluate(X_test, y_test)                 # [loss, accuracy]
print('Test accuracy:', score[1])

과적합 그래프: 학습셋 오차 vs 테스트셋 오차

  • 학습을 계속하면 학습셋 오차는 계속 줄지만, 테스트셋 오차는 줄다가 어느 순간 다시 커짐 → 그 지점부터 과적합, 더 학습할 이유가 없음
  • 논문 표(광물 데이터): 은닉을 늘릴수록 학습셋 정확도는 올라가 24개에서 100%, 하지만 테스트셋은 12개일 때 90.4%로 최고였다가 24개에서 89.2%로 떨어짐 (역전)
  • 식이 복잡해지고 학습량이 늘면 학습셋 예측률은 계속 오르지만, 적절히 조절하지 않으면 테스트셋 예측률은 오히려 떨어짐

모델 성능을 높이는 방법

  • 목표 = 학습셋에서만이 아니라 새 데이터에서 안정적으로 높은 정확도. 방법: 데이터의 양을 늘리고 질을 높이고 전처리 + 최적의 알고리즘 선택
  • 데이터 증강 = 데이터를 인위적으로 늘리는 방법. 이미지: 확대·축소, 회전 등으로 한 장에서 여러 샘플 / 테이블 데이터: 너무 튀는 값은 평균으로 바꾸거나 잘라냄, 시그모이드 등으로 0 ~ 1 사이 값으로
  • 알고리즘: 은닉층 개수·노드 수·활성화 함수·옵티마이저를 바꿔 가며 최적 구조를 찾음. 딥러닝 설정에 정답은 없음
  • 데이터에 따라 딥러닝이 아닌 랜덤 포레스트, XG부스트, SVM이 더 좋을 때도 있음 → 목적에 맞는 도구 선택

K겹 교차 검증

  • 결측치 = 측정값이 없는(빠진) 값 / 이상치 = 정상 범위에서 너무 벗어난 값

16장. 이미지 인식의 꽃, 컨볼루션 신경망(CNN)

MNIST 손글씨 데이터

  • CNN(컨볼루션 신경망, 합성곱 신경망) = 이미지·영상 같은 멀티미디어 데이터를 빠르게 학습하려고 만든 신경망. 테슬라 같은 카메라 기반 객체 탐지의 근간
  • 사람은 504192를 쉽게 읽지만, 컴퓨터가 5와 9와 6의 특징을 스스로 파악하게 하는 것은 오랜 과제
  • MNIST = 미국 국립표준기술원의 손글씨 숫자(0 ~ 9) 데이터. 7만 개 = 학습 6만 + 테스트 1만 (이미 나뉘어 있어 train_test_split 필요 없음)
  • 이미지 한 장 = 28 × 28 = 784픽셀, 픽셀마다 밝기 0 ~ 255 → 속성 784개 + 클래스 1개(0 ~ 9), 클래스 10개 중 하나를 맞히는 다중 분류

데이터 전처리: 1차원 변환 · 정규화 · 원-핫

  • reshape로 28 × 28 2차원 배열을 784개짜리 1차원 배열로 바꿈
  • 정규화(노멀라이제이션) = 데이터의 폭이 클 때 적절한 범위로 바꾸는 것. 케라스는 0 ~ 1 사이 값일 때 최적 → 0 ~ 255를 255로 나눔 (먼저 정수 → 실수 astype('float32')로 형 변환) → 풀이 ⑫
  • 클래스(0 ~ 9)는 to_categorical(y, 10)으로 원-핫 인코딩
  • 기본 딥러닝(입력 784 → 은닉 512 → 소프트맥스 10) → 정확도 약 98.16%
(X_train, y_train), (X_test, y_test) = mnist.load_data()       # 6만 / 1만
X_train = X_train.reshape(X_train.shape[0], 784).astype('float32') / 255
y_train = to_categorical(y_train, 10)                            # 원-핫 인코딩

컨볼루션 층: 커널(필터)과 특징 맵

  • 커널(필터) = 입력 데이터 위를 한 칸씩 움직이며 곱하고 더해서 특징을 추출하는 작은 행렬 / 특징 맵(피처 맵) = 커널을 적용해 얻은 결과 (컨볼루션 층 = 특징 맵, 같은 의미)
  • 커널을 적용하면 데이터가 줄어듦: 4 × 4 입력 + 2 × 2 커널 → 3 × 3 특징 맵 → 풀이 ⑩
  • 크기를 그대로 유지하고 싶으면 가장자리에 여백을 줌(패딩)
  • Conv2D(32, kernel_size=(3, 3), input_shape=(28, 28, 1), activation='relu') = 커널 32개, 크기 3 × 3, 입력 28 × 28 × 채널(1 = 흑백, 3 = 컬러)

맥스 풀링 · 드롭아웃 · 플래튼

  • 풀링(서브 샘플링) = 컨볼루션 결과가 여전히 크고 복잡할 때 한 번 더 축소하는 것 / 맥스 풀링 = 영역에서 가장 큰 값만 남김 (주로 씀) / 평균 풀링 = 영역의 평균값을 남김 → 풀이 ⑪
  • MaxPooling2D(pool_size=2) → 가로·세로가 절반 (4 × 4 → 2 × 2)
  • 드롭아웃 = 노드나 층이 많으면 과적합이 생기므로, 은닉층의 노드 일부를 랜덤하게 꺼서 과적합을 효과적으로 방지하는 기법. Dropout(0.25) = 노드의 25%를 끔 → 풀이 ⑬
  • 플래튼(Flatten) = 컨볼루션 층·맥스 풀링은 이미지를 2차원 배열로 다루므로, 이를 1차원 배열로 펼쳐 기본 층(Dense)에 넣을 수 있게 하는 함수
  • CNN 순서: 컨볼루션 → 컨볼루션 → 맥스 풀링 → 드롭아웃 → 플래튼 → Dense(128) → 드롭아웃 → 소프트맥스 10 → 정확도 약 99.17%, 학습도 더 빨리 끝남(23번째 에포크에서 중단)
model = Sequential()
model.add(Conv2D(32, kernel_size=(3, 3), input_shape=(28, 28, 1), activation='relu'))
model.add(Conv2D(64, (3, 3), activation='relu'))
model.add(MaxPooling2D(pool_size=(2, 2)))      # 절반으로 축소
model.add(Dropout(0.25))                       # 노드 25% 끔
model.add(Flatten())                           # 2차원 → 1차원
model.add(Dense(128, activation='relu'))
model.add(Dropout(0.5))
model.add(Dense(10, activation='softmax'))

강의에서 숫자를 짚어 준 계산을 모았습니다. 시험에서는 숫자만 바꿔 나올 수 있으니 순서를 외우고 연습 문제를 직접 풀어 보세요. 숫자를 바꾼 문제는 문제 → 계산 문제 풀어보기에서 적고 채점할 수 있습니다.

층 하나의 가중치 개수 = 앞 층 노드 수 × 뒤 층 노드 수 + 뒤 층 노드 수(바이어스)

풀이 ① 폐암 모델 가중치 개수 (10장)

구조: 입력 16 → 은닉 30 → 출력 1

  1. 입력 → 은닉: 16 × 30 = 480 + 바이어스 30 = 510
  2. 은닉 → 출력: 30 × 1 = 30 + 바이어스 1 = 31
  3. 합: 510 + 31 = 541개

연습 입력 10 → 은닉 20 → 출력 1 → (10 × 20 + 20) + (20 × 1 + 1) = 220 + 21 = 241

풀이 ② 피마 인디언 모델 가중치 개수 (11장)

구조: 입력 8 → 은닉 12 → 은닉 8 → 출력 1

  1. 8 × 12 + 12 = 108
  2. 12 × 8 + 8 = 104
  3. 8 × 1 + 1 = 9
  4. 합: 108 + 104 + 9 = 221개 (강의: “학습에 사용되는 파라미터가 221개”)

풀이 ③ 아이리스 모델 가중치 개수 (12장)

구조: 입력 4 → 은닉 12 → 은닉 8 → 출력 3

  1. 4 × 12 + 12 = 60
  2. 12 × 8 + 8 = 104
  3. 8 × 3 + 3 = 27 (출력 노드가 3개라 바이어스도 3개)
  4. 합: 60 + 104 + 27 = 191개

풀이 ④ 집값 모델 가중치 개수 (15장)

구조: 입력 5 → 10 → 30 → 40 → 출력 1

  1. 5 × 10 + 10 = 60
  2. 10 × 30 + 30 = 330
  3. 30 × 40 + 40 = 1,240
  4. 40 × 1 + 1 = 41
  5. 합: 1,671개

풀이 ⑤ 기울기 소실: 시그모이드 미분값 곱하기 (9장)

시그모이드 미분의 최댓값 = 0.25. 층을 지날 때마다 곱해진다고 하면 (가장 좋은 경우)

  1. 1층: 0.25
  2. 2층: 0.25 × 0.25 = 0.0625
  3. 3층: 0.0625 × 0.25 = 0.015625 (약 1.6%)

렐루는 x > 0이면 미분값 1 → 1 × 1 × 1 = 1 (그대로 전달)

풀이 ⑥ 에포크와 배치 사이즈 (10장)

문제: 샘플 480개, batch_size=16, epochs=5

  1. 한 에포크의 묶음 수 = 480 ÷ 16 = 30번 가중치 업데이트
  2. 전체 = 30 × 5 = 150번

강의 예제(470개 ÷ 16 = 29.4)처럼 나누어떨어지지 않으면 마지막 묶음은 남은 개수만큼 → 30묶음

풀이 ⑦ 소프트맥스 확률 (12장)

소프트맥스 출력은 모두 더하면 1 → 세토사 0.1, 버지컬러 0.3이면 버지니카 = 1 − 0.1 − 0.3 = 0.6 → 가장 큰 버지니카로 예측

풀이 ⑧ 데이터 나누기 (13 · 14장)

13장 샘플 100개, test_size=0.3 → 테스트 30개, 학습 70개

14장 샘플 1,000개

  1. test_size=0.2 → 테스트 1,000 × 0.2 = 200개, 남은 학습용 800개
  2. validation_split=0.25 → 검증 800 × 0.25 = 200개
  3. 실제 학습 800 − 200 = 600개 → 6 : 2 : 2

풀이 ⑨ K겹 교차 검증 평균 (13장)

5겹 정확도: 74%, 81%, 88%, 90%, 73%

  1. 합: 74 + 81 + 88 + 90 + 73 = 406
  2. 평균: 406 ÷ 5 = 81.2% (강의: “81% 정도”)

풀이 ⑩ 컨볼루션 결과 크기 (16장)

커널을 한 칸씩 옮길 때(여백 없음) 결과 한 변 = 입력 − 커널 + 1

  1. 4 × 4 입력, 2 × 2 커널 → 4 − 2 + 1 = 3 × 3
  2. 28 × 28 입력, 3 × 3 커널 → 28 − 3 + 1 = 26 × 26
  3. 한 번 더 3 × 3 → 26 − 3 + 1 = 24 × 24, 맥스 풀링(2) → 12 × 12

값 계산: 커널과 겹치는 칸끼리 곱해서 더함. 그림 예: 1×1 + 0×0 + 0×0 + 1×1 = 2

연습 6 × 6 입력, 3 × 3 커널 → 4 × 4, 맥스 풀링(2) → 2 × 2
